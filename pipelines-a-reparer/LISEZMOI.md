# Trois pipelines à réparer (fin du jour 2)

Chacun de ces fichiers contient **un seul bug**, différent à chaque fois.

Pour chaque pipeline (A, B, C) :

1. Copiez le fichier dans `.github/workflows/` sous un nom explicite, sur une branche dédiée.
2. Poussez : observez ce qui se passe dans l'onglet Actions (le workflow démarre-t-il ? où échoue-t-il ?).
3. Trouvez le bug en lisant les logs, corrigez, poussez : le run doit passer au vert.
4. Pour le dossier : une capture du run en échec, une capture du run réparé, et 3 lignes d'explication
   (quel était le bug, comment vous l'avez trouvé, comment l'éviter).

Supprimez ces workflows de test une fois l'exercice terminé, pour ne pas polluer votre dépôt.
